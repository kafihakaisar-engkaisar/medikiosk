1. Boot & Patient Onboarding Flow

Phase 1 · Entry

Patient approaches the kiosk terminal, selects their preferred regional dialect, and authenticates identity.

STEP 1.1
🚀 Kiosk Loader
2-second automated initialization check (no skip button) ensuring system integrity and camera readiness.
STEP 1.2
🌐 5-Language Picker
Dynamic i18n switcher: English, हिन्दी (Hindi), Hinglish, भोजपुरी (Bhojpuri), and اردو (Urdu).
STEP 1.3
🪪 Identity Sign-In
Supports ABHA Card Number, ABHA QR scanning (html5-qrcode), Demo account (MK-88219), or Guest Registration.
STEP 1.4
👤 Dynamic Topbar
Topbar flips dynamically from generic "Profile" to authenticated "Eleanor Vance | ID: MK-88219".
↓

2. Multimodal Symptom Intake & Pre-AI Safety Engine

Phase 2 · Clinical Safety

Patient reports symptoms via voice or touch; deterministic rules immediately intercept life-threatening alerts.

STEP 2.1
🎙️ Voice Speech-to-Text
Browser Web Speech API captures spoken Indian dialects in real-time and populates chief complaints.
STEP 2.2
🏷️ Touch Symptom Chips
Instant 1-click clinical chips: Fever, Persistent Cough, Chest Tightness, Knee Pain, Stomach Cramps.
STEP 2.3 · SAFETY
🚨 Red Flag Gatekeeper
Deterministic check (chest pain, cannot breathe, stroke, seizure). Overrides AI to dispatch emergency team if found.
↓

3. AI Interactive Clinical Triage

Phase 3 · Urgency Scoring

Interactive clinical dialogue evaluates progression and computes hospital queue urgency level.

STEP 3.1
💬 3-Question Chat
Assesses symptom onset duration, self-reported severity (Mild/Moderate/Severe), and worsening conditions.
STEP 3.2
⚖️ Urgency Categorization
Classifies encounter: 🟢 Routine (Low), 🟡 Priority (Medium), or 🔴 Emergency (High Priority).
STEP 3.3
🌐 Hybrid Failover
Communicates with Python FastAPI backend (/triage), with automatic zero-downtime offline fallback if disconnected.
↓

4. Medical Support Hub & AI Doctor Recommendation

Phase 4 · Department Routing

Symptom tokens are analyzed to recommend at least 3-4 specialized physicians with instant appointment booking.

STEP 4.1 · CORE FEATURE
👨‍⚕️ Doctor Recommendation
Keyword scoring algorithm matches symptoms to 8 specialist profiles. Computes match % (99%, 96%, 94%) and clinical reasoning.
STEP 4.2
🎟️ Instant Token Booking
Patient selects available doctor slot (e.g. 11:30 AM); generates Appointment Token (AP-983) and adds to live doctor queue.
STEP 4.3
🌿 Alternative Care (AYUSH)
Holistic pathways: Ayurveda, Yoga, Unani, Siddha, and Homeopathy with certified hospital vaidyas.
STEP 4.4
⚠️ Report Problem Modal
Direct trigger (#reportProblemModal) for reporting hardware/software kiosk issues straight to hospital admin.
↓

5. Clinical Summary, QR Generation & Privacy Reset

Phase 5 · Archival

Compiles full triage encounter, generates digital QR slip, persists records, and protects patient privacy.

STEP 5.1
📱 QR Code Slip
qrcodejs renders an instant scannable QR ticket containing clinical summary, booked doctor, and triage priority.
STEP 5.2
💾 Permanent Local Archival
Saves encounter to localStorage[medikiosk_patient_visits] ensuring complete history retention across browser reloads.
STEP 5.3
🔒 Privacy Guard on Finish
Clicking Finish Visit clears the active session and reverts the topbar back to generic "Profile" (no residual personal data).
↓

💻 Technology Stack

Modern & Resilient

🎨 Frontend Technologies

HTML5 Semantic SPA CSS3 Variables Vanilla JS (ES6+) Web Speech API LocalStorage API
  • Zero Framework Overhead: Fast boot time and instant touch response without heavy bundle compilation.
  • Custom i18n Engine: Real-time multilingual dictionary supporting English, Hindi, Hinglish, Bhojpuri, and Urdu.
  • Web Speech API: Native voice recognition for hands-free symptom entry in outpatient areas.

📦 Client-Side Libraries (CDNs)

html5-qrcode (v2.3.8) qrcodejs (v1.0.0)
  • html5-qrcode: Camera-based ABHA card and health QR scanning.
  • qrcodejs: Dynamic client-side rendering of scannable encounter tokens.

⚡ Backend & Server

Python 3.10+ FastAPI Uvicorn ASGI Pydantic python-multipart
  • FastAPI Framework: Asynchronous high-throughput REST API with automated OpenAPI docs.
  • Uvicorn Server: Lightning-fast asynchronous server running Python endpoints.
  • Pydantic Schemas: Strict validation for patient payloads and triage requests.

🗄️ Database & Persistence

SQLite3 (medikiosk.db) Custom Schema Migration Browser LocalStorage Local File Storage
  • SQLite3 Relational DB: Persistent relational tables for registered patients, visits, and histories.
  • Hybrid Offline Cache: Browser storage retains visit records, bills, and tickets even if backend is disconnected.

🔒 Security & Standards

SHA-256 Hashing CORS Middleware ABHA / ABDM FHIR/HL7 Schemas
  • Cryptographic Protection: User passwords hashed via SHA-256 before disk storage.
  • ABHA Integration: Structured around Ayushman Bharat Health Account identifiers.

🏛️ Architecture Highlights

MediKiosk uses an Offline-First Hybrid Model tailored for mission-critical public hospital deployment.

  • Single Page Architecture: Fast transitions between triage phases without browser page reloads.
  • Deterministic Safety Gate: Pre-AI safety rules guarantee emergency conditions are escalated immediately.
  • Role-Based Portals: Isolated workspaces for Kiosk Patients, Clinical Doctors, and System Administrators.
